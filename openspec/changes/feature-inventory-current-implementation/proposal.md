## Why

To provide a complete, documented feature inventory and specification of the current implementation of the Sound & Licht Stuttgart event technology rental website (Astro 7.x SSG, Tailwind CSS 4.x), ensuring all core functionalities, search capabilities, wishlist/merkliste management, content collections, and SEO structures are fully mapped and maintainable.

## What Changes

- Document all existing features and architectural components of the site.
- Create formal specifications for site capabilities including catalog management, pagefind search, client-side merkliste (wishlist) store, geographic city landing pages, FAQ system, and SEO JSON-LD structured data.

## Capabilities

### New Capabilities
- `feature-inventory`: Comprehensive documentation and verification of all existing site features, pages, components, and integrations.

### Modified Capabilities
- None (this is a documentation/inventory change capturing the existing implementation).

## Impact

- No breaking changes. Establishes a complete functional and architectural reference specification for the project.
